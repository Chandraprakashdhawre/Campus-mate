# CampusMate AI

## Run locally

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Demo sign-in

CampusMate provides browser-local registration, sign-in, and sign-out for demonstration purposes. Accounts are stored in the browser's local storage and do not sync between devices. This is not production authentication and must not be used with real or reused passwords; use a trusted authentication provider and server-side validation for production.

Use **Create account** on the sign-in screen to register, then sign out and sign back in to verify the account. Admin FAQ entries are saved in this browser and are available immediately to chatbot text and voice answers.
